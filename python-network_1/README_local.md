# Python - Network #1

Python scripts that fetch internet resources with urllib and requests:
GET and POST requests, headers, error codes, JSON and the GitHub API.

## Tasks

| File | Description |
|------|-------------|
| 0-hbtn_status.py | Fetches the intranet status with urllib |
| 1-hbtn_header.py | Displays the X-Request-Id header (urllib) |
| 2-post_email.py | Sends a POST request with an email (urllib) |
| 3-error_code.py | Displays the body or the HTTPError code (urllib) |
| 4-hbtn_status.py | Fetches the intranet status with requests |
| 5-hbtn_header.py | Displays the X-Request-Id header (requests) |
| 6-post_email.py | Sends a POST request with an email (requests) |
| 7-error_code.py | Displays the body or the error code (requests) |
| 8-json_api.py | Searches a user by letter and handles JSON results |
| 10-my_github.py | Displays your GitHub id using basic authentication |
