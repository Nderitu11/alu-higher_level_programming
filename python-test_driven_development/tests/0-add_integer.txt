===========================
How to use 0-add_integer.py
===========================

This module defines add_integer(a, b=98).

::

    >>> add_integer = __import__('0-add_integer').add_integer

Integers:

    >>> add_integer(1, 2)
    3
    >>> add_integer(100, -2)
    98
    >>> add_integer(-3, -4)
    -7
    >>> add_integer(0, 0)
    0

Default value of b:

    >>> add_integer(2)
    100

Floats are cast to integers:

    >>> add_integer(100.3, -2)
    98
    >>> add_integer(-5.9, -1.1)
    -6
    >>> add_integer(1.5, 2.5)
    3
