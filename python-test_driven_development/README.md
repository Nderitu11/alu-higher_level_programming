# Python - Test-driven development

Functions written TDD-style: docs and tests first, then the code.

| File | Description |
|------|-------------|
| `0-add_integer.py` | Adds two integers/floats (floats cast to int) |
| `2-matrix_divided.py` | Divides all elements of a matrix, rounded to 2 decimals |
| `3-say_my_name.py` | Prints `My name is <first> <last>` |
| `4-print_square.py` | Prints a square of `#` |
| `5-text_indentation.py` | Prints text with 2 new lines after `.`, `?` and `:` |
| `tests/6-max_integer_test.py` | Unittests for `6-max_integer.py` |

Doctests: `python3 -m doctest ./tests/*.txt`
Unittests: `python3 -m unittest tests.6-max_integer_test`
