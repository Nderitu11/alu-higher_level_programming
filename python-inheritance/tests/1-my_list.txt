Doctest for the MyList class
============================

>>> MyList = __import__('1-my_list').MyList

Sorting an unsorted list:

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]
>>> my_list.print_sorted()
[1, 2, 3, 4, 5]
>>> print(my_list)
[1, 4, 2, 3, 5]

Empty list:

>>> my_list = MyList()
>>> my_list.print_sorted()
[]

Already sorted list:

>>> my_list = MyList([1, 2, 3])
>>> my_list.print_sorted()
[1, 2, 3]

Reverse sorted list:

>>> my_list = MyList([3, 2, 1])
>>> my_list.print_sorted()
[1, 2, 3]

Negative numbers:

>>> my_list = MyList([3, -1, 0, -5])
>>> my_list.print_sorted()
[-5, -1, 0, 3]

Duplicates:

>>> my_list = MyList([2, 1, 2, 1])
>>> my_list.print_sorted()
[1, 1, 2, 2]

A single element:

>>> my_list = MyList([7])
>>> my_list.print_sorted()
[7]

It is still a list:

>>> isinstance(my_list, list)
True
