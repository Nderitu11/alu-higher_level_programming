# Python - More Classes and Objects

Deeper look at object-oriented programming in Python 3. Each file builds
on the previous one to define a `Rectangle` class: properties, string
representations (`__str__` / `__repr__`), `__del__`, class attributes,
static methods and class methods.

| File | Description |
|------|-------------|
| 0-rectangle.py | Empty class Rectangle |
| 1-rectangle.py | Width and height with validation |
| 2-rectangle.py | Area and perimeter |
| 3-rectangle.py | `__str__` printing with # |
| 4-rectangle.py | `__repr__` usable with eval() |
| 5-rectangle.py | Message on instance deletion |
| 6-rectangle.py | Class attribute counting instances |
| 7-rectangle.py | Class attribute print_symbol |
| 8-rectangle.py | Static method bigger_or_equal |
| 9-rectangle.py | Class method square |
